# レトロゲームコレクション管理

Spring Boot + PostgreSQL で作るレトロゲームのコレクション管理Webアプリです。

## 主な機能

- ゲーム登録
- ゲーム一覧
- ゲーム名・ハード・メーカー・ジャンル検索
- ゲーム詳細
- 画像保存
- 箱の有無
- 説明書の有無
- 購入価格・購入日・発売日・備考
- PostgreSQLによる永続保存

## 起動前の準備

PostgreSQLに `retro_game` データベースを作成してください。

デフォルト設定は以下です。

- DB: retro_game
- User: postgres
- Password: postgres
- Port: 5432

環境に合わせて `application.properties` または環境変数を変更してください。

## 起動

```bash
mvn spring-boot:run
```

ブラウザで

```text
http://localhost:8080/
```

を開きます。

## 画像について

画像データはPostgreSQLの `bytea` として保存します。
そのため、アプリを再起動しても登録画像はDBに残ります。


## ハードウェア

日本で発売・流通した主要な家庭用・携帯型ゲーム機を登録画面の選択肢として収録しています。


## ハードウェアマスタ
ハードはHTMLに直接書き込まず、PostgreSQLの`hardwares`テーブルで管理します。
起動時に`data.sql`から日本で流通した主要な家庭用・携帯型・その他のゲーム機を初期登録し、登録画面は`GET /api/hardwares`から一覧を取得します。
ハードの追加・変更を行ってもHTMLを修正する必要がありません。

Nintendo Switch 2もマスタに含めています。任天堂公式情報では日本で2025年6月5日に発売されています。


## コレクション集計

`/stats.html` では、登録ゲーム数、購入金額合計、箱あり率、説明書あり率、ハード別の所持本数を確認できます。ハード別集計はSQLデータベースから取得するため、ゲームを登録・削除すると集計にも反映されます。
